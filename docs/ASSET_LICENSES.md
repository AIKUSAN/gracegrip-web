# Bundled visual assets

## Open Peeps avatar catalog

The 12 files under `public/avatars/open-peeps/` are locally bundled SVG outputs of the Open Peeps style. Original artwork: **Open Peeps by Pablo Stanley**, [openpeeps.com](https://www.openpeeps.com/), CC0 1.0. The files were generated on 2026-09-25 using DiceBear's [Open Peeps style](https://www.dicebear.com/styles/open-peeps/) at `https://api.dicebear.com/10.x/open-peeps/svg?seed=<filename>`, then saved unchanged. DiceBear identifies this style as a remix of the CC0 original. No avatar request is made to DiceBear when someone uses GraceGrip.

The filenames are arbitrary, gender-neutral catalog IDs. People choose the image they prefer; GraceGrip does not assign a gender to any artwork. The SVGs have been checked for scripts and external links. Their SHA-256 values at import are listed below so later edits can be distinguished from the source outputs.

## Helpline country links

`src/data/helplineCountries.json` contains only country names and link codes extracted from the public [Find A Helpline country directory](https://findahelpline.com/) on 2026-09-25. IASP links to this directory for global crisis support. GraceGrip does not copy or cache helpline phone numbers or claim the directory is an emergency service; the source site maintains the service details.
